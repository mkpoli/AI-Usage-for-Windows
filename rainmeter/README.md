# AI Usage Rainmeter skins

Desktop widgets showing AI coding subscription usage, read from the AI Usage
tray app over loopback.

Copy the `AI Usage` folder here into `Documents\Rainmeter\Skins`, so it sits
at `Documents\Rainmeter\Skins\AI Usage`. Turn on **Settings > Desktop
Widgets** in AI Usage, then refresh Rainmeter and load a skin from
**Skins > AI Usage**. One skin per provider; load the ones you want.

Setup details, the endpoint format, and how to build your own skin on it are in
[docs/rainmeter.md](../docs/rainmeter.md).
